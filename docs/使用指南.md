# PRT 阅读器 使用指南

> 编写：软体程式部　　评议通过：专家委员会

本文档面向最终使用者，说明 PRT 阅读器的功能范围与操作方式。

**怎么装起来**：普通用户用自研 WPF 安装器（单个 exe，双击进向导，不需要管理员权限，
默认把 `.prt` / `.psr` / `.mdp` 三类文件一并绑定）；批量部署可用静默安装参数。
详见 [安装说明](安装说明.md)。

---

## 一、功能概述

PRT 阅读器是一套面向 PRT（Perisc Standard Richtext）的**解析、查看与编辑**工具，界面全部由
WPF 原生控件实现（不使用 WebView 或浏览器内核），提供「左源码、右预览」的即时呈现方式。

主要能力如下：

| 能力 | 说明 |
| --- | --- |
| 多标签编辑 | 同时打开多个文档，标签显示文件名与未保存标记 |
| 实时预览 | 编辑后自动重新解析并刷新预览（约 280 毫秒防抖；超大文档自动拉长防抖间隔） |
| 原生预览渲染 | 语法树逐块渲染为原生 WPF 元素，预览区为虚拟化阅读器（只实例化视口内的块），非 HTML 中转 |
| 目录导航 | 依据自动编号的章节层级生成树形目录，点击跳转预览位置；列表启用虚拟化，超大文档（数千章节）默认只展开前两级 |
| 诊断面板 | 按《PRT 标准》14.4 汇总错误 / 警告，标注 `行:列`、代码与说明，双击定位源码 |
| 查找替换 | 支持区分大小写、逐个替换与全部替换 |
| 主题切换 | 界面配色（浅色 / 深色）全局生效；深色界面下预览显示区同步使用深色。预览主题（PRT 主题）可另行显式指定 |
| 三格式导出 | HTML、Markdown（兼容子集无损 + 显式降级）、纯文本 |
| 缩放与换行 | 50%–300% 缩放、编辑器自动换行开关 |
| 严格 / 宽松模式 | 严格模式下语法问题按错误处理；宽松模式下降级并给出警告 |
| 激活与授权 | 离线激活码（RSA-2048 签名校验，全程不联网）；界面展示授权等级、签发明细与本副本激活次数 |
| 关于 | 独立窗口：品牌标、版本、符合性等级、功能一览与当前授权 |
| 启动自检 | 命令行 `--selftest` 验证解析、渲染、导出与安全模块链路（54 项） |
| 安全中心 | 菜单「帮助 → 安全中心…」：查看 / 撤销许可、检索与导出审计、查看行为清单全文 |

**功能边界（重要）**：本工具实现 PRT 的 **CORE 与 EXT** 等级，**不支持 COMP（受限计算）**。
详见 [符合性声明](符合性声明.md)（其中也列明了声明基准版本与当前发布标准之间的已知差距）。

**启动方式**：程序按 PSS 接入模式 A 接入安全模块，主程序是 DLL，**唯一入口是宿主启动器**。

**双击 `Perisc.Safety.SafeGuard.exe` 即可**，不需要任何参数——启动器会在同目录内找到主程序，
并显示一个「安全系统启动中」的图形界面（启动器是 GUI 子系统程序，双击时**不会出现控制台窗口**）。
该界面显示的是真实阶段（校验运行体完整性 → 启动主程序 → 等待主程序接入），**至少显示 800 ms**：
启动器先把界面显示满 800 ms，再启动阅读器（故这段时间里不会冒出别的窗口压住它），
主程序接入后界面淡出，紧接着是阅读器自己的启动画面；它只在双击时出现，从命令行启动时不显示，
也不需要你操作。需要从命令行指定文档时用（`--program` 可省略）：

```
Perisc.Safety.SafeGuard.exe [--program Prt.App.dll] -- "要打开的文档.prt"
```

双击 `Prt.App.dll` 不会有任何反应：DLL 不是可执行体，这是接入模式 A 刻意如此。
启动器在加载主程序前会校验运行体哈希，不一致即拒绝启动（双击时以弹窗告知原因，
不会一闪而过）——升级时请把启动器与主程序一起替换。

**安全提示**：敏感行为（读写文件、剪贴板等）默认需要用户授权，首次触碰某个对象时会
弹出授权窗；选「本次会话内允许」可减少重复询问。全部行为与存储位置见[行为清单](行为清单.md)。

## 二、操作流程

### 2.1 启动与打开

| 操作 | 方式 |
| --- | --- |
| 新建文档 | 菜单「文件 → 新建」，或 `Ctrl+N` |
| 打开文档 | 菜单「文件 → 打开」，或 `Ctrl+O`（可多选） |
| 打开示例 | 菜单「文件 → 打开示例文档」，加载程序目录下的 `samples/sample.prt` |
| 命令行打开 | `Perisc.Safety.SafeGuard.exe -- "路径\文档.prt"`（`--program` 可省略） |
| 关闭标签 | 标签上的 `✕`，或 `Ctrl+W` |
| 关闭全部标签 | 菜单「文件 → 关闭全部标签」 |

### 2.2 编辑与预览

1. 启动后默认进入**分栏**模式：左侧为源码编辑区（等宽字体），右侧为实时预览。
2. 在左侧输入或修改内容，停顿约 0.3 秒后右侧自动刷新。
3. 通过菜单「视图」或工具栏在三种模式间切换：**仅源码编辑 / 分栏 / 仅预览**。
4. 中间分隔条可拖动，用于调整两栏宽度比例。
5. 两栏滚动位置按比例同步（分栏模式下生效）。
6. 预览支持**就地编辑**：**双击**预览中的块，该块原地变为源码编辑框（此时预览滚动暂时锁定，
   保证编辑位置不漂移）；`Ctrl+Enter` 或点击外部**提交**（写回源码并刷新预览），`Esc` **取消**。
   单击预览中的块仍是定位源码；右键提供定位 / 就地编辑 / 插入框 / 插入段落 / 删除块。

### 2.3 目录与诊断

- **目录面板**：位于左侧。显示 `::: section` 与基础标题（`#`…`######`）构成的层级与自动编号；
  点击任一条目即在预览中滚动到对应位置。菜单「视图 → 显示目录面板」或工具栏「目录」可隐藏/显示。
- **诊断面板**：默认隐藏。菜单「视图 → 显示诊断面板」或工具栏「诊断」打开。
  列表包含四列：位置（`行:列`）、级别、代码（如 `PRT0015`）、说明。
  **双击**任一行，编辑器光标定位到对应源码位置。
- 状态栏右下角实时显示「错误 N · 警告 M」，若文档含 COMP 结构则追加「含 COMP 降级」。

### 2.4 查找与替换

1. 按 `Ctrl+F` 打开查找条（`Ctrl+H` 同时展开替换输入框）。
2. 输入查找内容，「下一个」逐个定位；`F3` 可继续查找下一个。
3. 「替换」替换当前匹配并跳到下一处；「全部替换」替换所有匹配并提示替换数量。
4. 「区分大小写」控制是否按严格大小写匹配。
5. 「关闭」或 `Esc` 之外的任意位置点击可退出；关闭后焦点回到编辑器。

### 2.5 保存与导出

| 操作 | 方式 |
| --- | --- |
| 保存 | `Ctrl+S`（未命名文档会弹出保存对话框） |
| 另存为 | `Ctrl+Shift+S` |
| 重新载入 | 菜单「文件 → 重新载入」（放弃未保存修改前会二次确认） |
| 导出 HTML | 菜单「文件 → 导出为 HTML」，或工具栏按钮 |
| 导出 Markdown | 菜单「文件 → 导出为 Markdown」 |
| 导出纯文本 | 菜单「文件 → 导出为纯文本」 |

编码约定：读写一律使用 **UTF-8**；读取时自动剥离 BOM，写入时不写 BOM。

### 2.6 主题

- **界面配色**（菜单「主题 → 界面配色」）：浅色 / 深色，全局作用于编辑器、面板、状态栏与预览显示区。
- **预览主题**（菜单「主题 → 预览主题」）：`跟随文档声明` / `default` / `dark` / `print` / `accessible`。

「跟随文档声明」默认使用文档 `::: meta` 中的 `theme` 键；若文档内通过 `::: theme` 块
声明了自定义主题，则优先使用文档内声明，并按第 12.2 节叠加覆盖附录 C 的样式变量。
**深色界面下**，预览显示区跟随界面使用深色主题，文档声明的浅色主题（如 `theme: default`）
不会把预览拉回白底；如确需按文档主题显示，请在「预览主题」中显式选择。

### 2.7 模式与缩放

| 操作 | 方式 |
| --- | --- |
| 强制严格模式 | 菜单「视图 → 强制严格模式」 |
| 自动换行 | 菜单「视图 → 编辑器自动换行」 |
| 放大 / 缩小 | `Ctrl+加号` / `Ctrl+减号` |
| 重置缩放 | `Ctrl+0` |

**严格模式语义**：默认**未勾选**，此时遵循文档内 `::: meta` 的 `strict` 声明
（未声明时按严格处理）。勾选后忽略文档内声明，一律按严格模式解析。
宽松模式下不合格的写法会被降级并给出警告，仍可正常预览与导出。

### 2.8 快捷键汇总

| 快捷键 | 功能 | 快捷键 | 功能 |
| --- | --- | --- | --- |
| `Ctrl+N` | 新建 | `Ctrl+F` | 查找 |
| `Ctrl+O` | 打开 | `Ctrl+H` | 替换 |
| `Ctrl+S` | 保存 | `F3` | 查找下一个 |
| `Ctrl+Shift+S` | 另存为 | `Ctrl+A` | 全选 |
| `Ctrl+W` | 关闭标签 | `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+加号` | 放大 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 剪切 / 复制 / 粘贴 |
| `Ctrl+减号` | 缩小 | `Ctrl+0` | 重置缩放 |

### 2.9 激活与关于

| 操作 | 方式 |
| --- | --- |
| 激活与授权 | 菜单「帮助 → 激活与授权…」 |
| 关于 | 菜单「帮助 → 关于…」 |
| 符合性声明 / 快捷键 | 菜单「帮助 → 符合性声明…」/「帮助 → 快捷键…」，或「关于」窗口底部按钮 |

**激活窗口**展示当前授权（未激活 / VIP（限时）/ 永久授权）、签发明细（签发时间、授权量、签发人、
签发理由）与各等级权益。把整行激活码粘贴进输入框后点「激活」即完成离线校验与落盘；结果与失败原因
显示在窗口底部。窗口高度上限为屏幕工作区的 90%：授权信息过长时**正文区域内滚动**，
「激活码输入 + 结果提示 + 按钮」始终固定在底部可见。

**授权文件与激活计数**写在**可执行文件同级**目录：

| 文件 | 内容 |
| --- | --- |
| `license.key` | 离线激活码原文（签名验证通过后才写入） |
| `activations.json` | 本副本的激活次数计数（界面显示为「本副本已激活 x 次」） |

授权**按副本隔离**：本机若存在多份程序副本，各副本只认自己目录下的 `license.key`——
在其中一份激活**不会**点亮其余副本；反之把整个程序目录复制到别处，副本会保留已激活状态。
因此授权文件所在目录必须可写；只读目录下激活无法留存，激活窗口会明确给出写入失败原因。

## 三、PRT 语法速查

### 3.1 文档元信息

```
::: meta
title: 文档标题
subtitle: 副标题
author: 作者
date: 2026-09-13
lang: zh-CN
theme: default
numeration: mixed
toc: true
tags: 标签一, 标签二
glossary: PRT=Perisc Standard Richtext 文档格式标准; EXT=扩展等级
::: end meta
```

- 每行形如 `键: 值`；`glossary` 的值为 `<术语>=<定义>`，多条以 `;` 分隔。
- `numeration` 取 `mixed`（默认）/ `cn` / `arabic` / `roman` / `none`。

### 3.2 行内标记

| 写法 | 效果 | 写法 | 效果 |
| --- | --- | --- | --- |
| `**粗**` | 加粗 | `==高亮==` | 高亮 |
| `*斜*` | 斜体 | `+下划线+` | 下划线 |
| `***粗斜***` | 加粗斜体 | `^上标^` | 上标 |
| `~~删除~~` | 删除线 | `~下标~` | 下标 |
| `` `代码` `` | 行内代码 | `^[脚注内容]` | 脚注 |
| `[[kbd:Ctrl+S]]` | 按键 | `%%注释%%` | 不进入渲染的注释 |

颜色、背景与字号为成对指令：

```
[[color:red]]红色文字[[/color]]
[[bg:yellow]]黄色底纹[[/bg]]
[[size:large]]放大一档[[/size]]
```

命名色共 20 种（`black`、`white`、`gray`、`navy`、`red`、`orange`、`yellow`、`green`、
`teal`、`blue`、`purple`、`cyan`、`magenta`、`brown`、`olive`、`maroon`、`danger`、
`warning`、`info`、`success`）。使用非法颜色在严格模式下报错。

### 3.3 语义块

```
::: note 可选标题
正文内容。
::: end note
```

类型：`note`、`warning`、`danger`、`attention`、`example`、`definition`、`quote`、`comment`
（CORE）；`info`、`tip`、`result`、`task`（`todo` 为 `task` 的别名）（EXT）。

### 3.4 表格

简化管道表（CORE）：

```
| 季度 | 收入 | 备注 |
| :--- | ---: | :---: |
| Q1 | 100 | 含税 |
```

完整表格（EXT）支持跨列 `++` / `++N`、跨行 `^^` / `^^N`、表尾分隔 `|==|`：

```
::: table id="t-plan" caption="里程碑计划" align="center"
| 阶段 | 主负责 | ++ |
| 名称 | 部门 | 交付 |
| :-- | :-: | :-: |
| 需求 | 产品部 | 规格说明 |
| 开发 | ^^ | 可运行版本 |
|==|
| **合计** | 2 | 2 项 |
::: end table
```

合并规则：`++` 表示左侧主格向右多跨 1 列（`++N` 多跨 N 列）；`^^` 同理向下。
**禁止链式合并**（主格本身不可再被合并），表尾与表头跨行受限。

### 3.5 章节、编号与交叉引用

```
::: section id="sec-arch" title="架构分层"
内容……
::: end section
```

- 章节与基础标题共用编号计数器，样式由 `numeration` 决定。
- 目录：`[[contents depth=3 mode=numbered]]`（`mode=numbered` 仅列出参与编号的章节）。
- 交叉引用：`[[ref:目标ID]]`、`[[ref:目标ID|自定义文本]]`。
- 术语链接：`{术语}`、`{术语|自定义文本}`（术语须在 `meta.glossary` 登记）。
- 别名登记：

```
::: refs
设计 = sec-arch | 架构分层
::: end refs
```

参考文献默认显示文本（如章节输出「第一章」、表输出「表1」、图输出「图1」、公式输出「式(1)」）
一律依据目标类型的编号样式在结构解析阶段自动推导，文档调整顺序后引用自动更新。

### 3.6 布局块（EXT）

```
::: columns cols=2
::: column
左栏内容。
::: end column
::: column
右栏内容。
::: end column
::: end columns

::: collapse title="点击展开：补充说明" default-open=false
折叠内容。
::: end collapse

::: tabs
::: tab name="方案 A"
方案 A 的内容。
::: end tab
::: tab name="方案 B"
方案 B 的内容。
::: end tab
::: end tabs
```

### 3.7 图、公式与摘要

```
::: figure id="fig-flow" caption="处理流水线示意"
![流水线示意](assets/pipeline.png)
::: end figure

::: equation id="eq-euler" caption="欧拉恒等式"
e^{i \pi} + 1 = 0
::: end equation

::: summary
独立于正文的摘要，忽略章节编号。
::: end summary
```

### 3.8 COMP 结构（本工具不支持）

```
值 = {{ 单价 * 数量 }}          →  按原文输出「值 = {{ 单价 * 数量 }}」
::: run                           →  按代码块呈现，保留源码，不求值
let 总额 = 单价 * 数量;
::: end run
```

## 四、参数说明

### 4.1 命令行参数

启动器（`Perisc.Safety.SafeGuard.exe`）与主程序的参数以 `--` 分隔：`--` 之前是启动器的，
之后全部透传给主程序。

**启动器参数**

| 参数 | 说明 |
| --- | --- |
| `--program <主程序.dll>` | 要加载并启动的主程序运行体（本程序为 `Prt.App.dll`）。**可省略**：省略时在启动器所在目录内推断「除自身外唯一带同名 `.runtimeconfig.json` 的 DLL」；候选不唯一时报错，不猜。双击启动走的正是这条 |
| `--program-id <标识>` | 程序标识，默认取主程序文件名（本程序为 `Prt.App`）；用于审计与白名单分组。该值由启动器**注入子进程**（环境变量 `PERISC_SAFEGUARD_PROGRAM_ID`），主程序不自取名，两侧因此必然一致 |
| `--hash sha256:…` | 显式声明运行体哈希，**优先级最高**。不提供时用程序目录 `Safe.data` 里的出厂基准；两者都拿不到、或与运行体不一致，都**拒绝启动** |
| `--pipe <管道名>` | 守护通信的命名管道名，默认 `Perisc.Safety.Guard.v1` |
| `--instances <1~64>` | 管道并发实例上限，默认 8 |
| `--dotnet <dotnet.exe>` | 指定 dotnet 宿主路径。不提供时按序解析：环境变量 `DOTNET_HOST_PATH` → 由当前运行时目录上溯到 dotnet 安装根 → `PATH` 中的 `dotnet` |
| `-- <参数…>` | 其后全部透传给主程序 |

**主程序参数**（写在 `--` 之后）

| 参数 | 说明 |
| --- | --- |
| `<文件路径> …` | 直接打开一个或多个文档；已打开的文档会切换到对应标签 |
| `--selftest [报告路径]` | 启动自检：验证解析、原生渲染、三格式导出与安全模块链路（54 项），结果写入报告文件后退出 |

### 4.2 解析选项（`PrtOptions`）

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| `Strict` | `true` | 严格模式：语法错误、未知块类型、非法颜色、未闭合围栏、引用不存在目标均为错误 |
| `StrictOverride` | `null` | 显式覆盖文档内 `strict` 声明；`null` 表示交由文档声明决定 |
| `EnableComputation` | `false` | 【COMP 不支持】恒被忽略：无论取值如何都绝不对 COMP 结构求值 |
| `MaxFenceDepth` | `64` | 围栏最大嵌套深度，抵御深嵌套造成的拒绝服务 |
| `MaxTableColumns` | `128` | 表格最大列数，防止超宽表导致资源失控 |
| `Target` | `Html` | 渲染目标，影响降级路径 |

## 五、常见问题（FAQ）

**Q1：为什么 `{{ 表达式 }}` 显示的是一串原文而不是计算结果？**
本工具不支持 COMP（受限计算）等级，按标准第 13 章降级为原文输出，这是预期行为，
诊断面板会出现 `PRT0009` 提示。同理，`::: run` 等计算块会以代码形式呈现并保留全部源码。

**Q2：`[[contents depth=2]]` 写对了吗？为什么提示未知指令？**
`[[contents depth=2]]`（空格分隔）与 `[[contents:depth=2]]`（冒号分隔）均受支持。
若出现 `PRT0015`，请检查括号是否为半角 `[[ ]]`、指令名是否为 `contents` / `kbd` / `ref` /
`term` / `color` / `bg` / `size`。

**Q3：预览里的公式为什么不是排版后的数学式？**
公式块按标准第 13 章以降级方式呈现（等宽源码文本），本工具不包含公式排版引擎。

**Q4：预览中的图片显示为「[图片] …」占位符。**
为保障离线一致性与安全，本工具只加载**本地文件**图片（相对路径按文档所在目录解析），
不加载 `http://` / `https://` 远程图片；文件不存在或格式不受支持时同样显示占位符。

**Q5：为什么会提示表格「禁止链式合并」？**
合并的目标格若本身已被合并（即主格被再次当作被合并格），即构成链式合并，标准 10.3 禁止。
请改为让每个合并标记直接指向原始主格。

**Q6：文档里明明有 `strict: false`，为什么仍按严格模式报错？**
若菜单「视图 → 强制严格模式」处于勾选状态，则渲染器配置优先于文档声明（标准 14.4）。
取消勾选后即恢复为「遵循文档声明」。

**Q7：编辑过程中预览会闪动或短暂滞后。**
预览采用约 280 毫秒防抖重新解析（超大文档自动拉长防抖间隔，减少无谓重排）。
预览区是**虚拟化阅读器**：解析在后台完成，预览只把视口内的块实例化为界面元素，
滚动到哪渲染到哪——打开超大文档（数万行）不再需要等待整篇布局，期间预览顶部显示解析进度条。

**Q8：设置保存在哪里？换台电脑要不要重设？**
设置、会话（上次打开的文档）、自定义启动图与异常日志都保存在**程序所在文件夹**里，
不写用户配置目录。因此把整个程序目录复制到另一台电脑（或 U 盘）时，设置会一并带走；
同一台机器上放多份程序副本，它们各自的设置互不干扰。授权文件也遵循同样的"纯便携"策略。

**Q9：弹出「设置未能保存：程序所在文件夹不可写」怎么办？**
说明程序被放在了只读目录（典型如 `Program Files`）。本工具是绿色免安装形态，全部自身数据
只写程序所在文件夹、不支持写到别处。把整个程序目录复制到可写位置（如桌面或 `D:\` 下的自建目录）
再运行即可；授权激活遇到只读目录也会给出同样的提示。

> 从旧版本升级：早期版本的设置曾保存在 `%APPDATA%` 下。首次启动时程序会把其中的设置、会话与
> 启动图搬到程序目录（搬好并核对一致后删除旧文件），之后不再读写 `%APPDATA%`。旧目录中的
> 授权文件不会被读取、也不会被删除。
自动目录（`[[contents]]`）条目很多时（超过 300 条），预览里的目录默认收起为一行「目录（N 条，点击展开）」，
点击后才展开明细——避免超大目录拖慢打开；侧边栏大纲不受影响（超大文档只展开前两级）。
脚注区随预览一并就绪，不阻塞界面。

**Q8：能否导出 PDF / Word？**
当前版本不支持。HTML 导出结果可在浏览器中打印为 PDF；如需 DOCX，需另行转换。

**Q9：编辑器的撤销栈有多深？**
500 步（`UndoLimit = 500`）。

**Q10：标签页未保存标记 `*` 的含义？**
表示该文档自打开或上次保存以来发生过修改。关闭标签、关闭全部标签或退出程序时，
会针对存在未保存修改的文档逐一确认。

**Q11：激活后重启又变回未激活？**
授权文件写在可执行文件同级目录，若该目录不可写（例如程序装在 `Program Files` 下），
激活只在本次运行内有效；此时激活窗口底部会明确给出写入失败原因。请把程序移到可写目录
（本工具为绿色免安装，整目录复制即可）后重新激活。

**Q12：本机装了两份，为什么在其中一份激活后，另一份没有跟着激活？**
这是预期行为。授权按副本隔离，各副本只认自己目录下的 `license.key`，互不影响；
需要同时使用时请在每一份里分别激活。界面上的「本副本已激活 x 次」按副本分别累计，
既不是全机统计也不是联网统计（本工具全程不联网）。
